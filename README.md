# 应急物流仿真平台演示

[打开在线演示](https://emergency-logistics-demo-20261016.deep-peach-4015.chatgpt.site/)

## 本地运行

优先打开 `index.html`，也可打开 `应急物流仿真平台 (15)-优化版.html`。请使用 Edge 或 Chrome，并保持 HTML 文件与整个 `assets/` 文件夹在同一目录。跨电脑使用时，复制整个项目文件夹，或使用 `应急物流仿真平台_跨设备便携版.zip`；不要只复制 HTML，也不要单独打开 CSS/JS 文件。

Leaflet 地图库的 CSS 和 JavaScript 已随项目本地提供，不依赖外部 CDN。卫星影像和实时道路服务需要网络；网络不可用时会切换到内置离线矢量示意图。视频、语音及页面样式和脚本均从 `assets/` 本地加载。

建议使用电脑上的 Chrome 或 Edge，按 F11 全屏。点击仿真控制台中的开始按钮启动演示，可使用“上一幕”“下一幕”和速度按钮控制流程，点击“复位”重新演示。

## 文件说明

- `index.html`：默认演示入口。
- `应急物流仿真平台 (15)-优化版.html`：优化版单页入口。
- `assets/`：本地 Leaflet 库、页面样式和脚本、监控视频及语音素材。
- `物资数量核对说明.md`：96人首日物资配比、来源仓库、运输签收及库存余额核对明细。
- `scripts/verify-supply.cjs`：物资数量回归检查，安装 Node.js 后执行 `node scripts/verify-supply.cjs`。
- `跨设备运行说明.txt`：跨电脑复制和打开方式。
- `演示脚本-自主应急平台AI自动调度（详细版）.md`：详细讲解脚本。
- `自主应急平台AI自动调度演示故事脚本（优化版）.docx`：Word 演示脚本。
